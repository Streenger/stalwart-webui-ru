# Как переводить

В веб-интерфейсе Stalwart два источника текста.

## 1. Тексты самого интерфейса

Файл `src/i18n/ru.json` (английский оригинал: `src/i18n/en.json`). Это кнопки, сообщения, подписи общих элементов. Используется библиотека i18next. Для русского языка у слов, зависящих от числа, нужны четыре формы: `_one`, `_few`, `_many`, `_other`. Пример:

```json
"value.itemCount_one": "{{count}} элемент",
"value.itemCount_few": "{{count}} элемента",
"value.itemCount_many": "{{count}} элементов",
"value.itemCount_other": "{{count}} элемента"
```

Места подстановки (`{{count}}`, `{{name}}`) менять нельзя.

## 2. Текст из схемы сервера

Названия разделов, форм, полей, пояснения к полям, описания объектов приходят с сервера в ответе `GET /api/schema` на английском. Их подменяет `src/lib/localizeSchema.ts`, используя словарь `src/i18n/schema-ru.json`: ключ — английский текст точно как в схеме, значение — русский перевод.

Как найти непереведённое:

1. Получите схему вашего сервера. В браузере, после входа в панель, в консоли разработчика выполните запрос к `/api/schema` с вашим токеном и сохраните ответ как `schema.json` (токен сеанса виден в заголовке `Authorization` запросов на вкладке «Сеть»).
2. Запустите `node scripts/extract-strings.mjs schema.json --out untranslated.json`.
3. Заполните значения в `untranslated.json`, добавьте записи в `src/i18n/schema-ru.json`, выполните `npm run build`.

Скрипт не включает технические перечисления (`Permission`, `EventType`, `MetricType`): их названия оставлены на английском, как в документации Stalwart. Названия языков и часовых поясов формируются кодом через `Intl.DisplayNames`.

## Глоссарий

| Английский | Русский |
|---|---|
| account | учётная запись |
| mailbox (в JMAP) | папка |
| listener | слушатель |
| queue | очередь |
| quota | квота |
| role / permission | роль / право |
| certificate | сертификат |
| directory | каталог |
| tenant | арендатор |
| principal | субъект |
| blob store | хранилище объектов данных |
| mailing list | список рассылки |
| calendar / address book | календарь / адресная книга |
| spam filter | спам-фильтр |
| hook | хук |
| webhook | веб-хук |

Единицы, протоколы и названия технологий (SMTP, IMAP, JMAP, DKIM, DMARC, ACME, OAuth, Sieve) оставляйте латиницей.

## Проверка

Перед отправкой изменений выполните `npm run typecheck`, `npx eslint src/` и `npm run build`.
